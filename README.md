# Shqella Admin

A lightweight, Python-based admin panel and backend management system built with Flask and HTML templates.

## 📁 Project Structure

```text
shqella-admin/
├── templates/         # HTML templates for the UI
├── app.py             # Main Flask application entry point
├── database.py        # Database connection and models
├── modules.txt        # Project dependencies/modules list
└── .env               # Environment configuration file

```

## 🚀 Tech Stack

* **Backend:** Python, Flask
* **Frontend:** HTML, CSS
* **Database:** Python-integrated database management

## ⚙️ Getting Started

### Prerequisites

Make sure you have Python installed on your machine.

### Installation & Setup

1. **Clone the repository:**
```bash
git clone [https://github.com/sami9644/shqella-admin.git](https://github.com/sami9644/shqella-admin.git)
cd shqella-admin

```


2. **Configure environment variables:**
Set up your `.env` file with the necessary credentials and configurations.
3. **Install dependencies:**
```bash
pip install -r modules.txt

```


*(Note: If using `modules.txt` directly, you can install packages as specified in the file).*
4. **Run the application:**
```bash
python app.py

```
